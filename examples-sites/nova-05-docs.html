Getting started / Install

Install the CLI

The Meridian CLI links a local project to a workspace, pulls metric definitions and pushes mapping changes without leaving the terminal.

v3.1StableNode 20+

Heads up. The CLI only writes mapping files. It never modifies billing data or sends events to your customers.

1. Install

terminalnpm
npm install -g meridian-cli
meridian login --workspace northwind
meridian pull --metrics

2. Connect a workspace

Authentication opens a browser session and stores a scoped token in your OS keychain. Tokens are workspace-bound and expire after 90 days unless rotated.

meridian.ymlyaml
workspace: northwind
default_range: last_30_days
metrics:
  - net_revenue_retention
  - gross_churn
  - expansion_mrr
export:
  warehouse: snowflake
  schema: analytics_meridian

3. Verify the sync

CommandWhat it returnsTypical runtime
meridian statusWorkspace, token expiry, last sync0.4s
meridian checkMapping differences before pushing1.1s
meridian pushApplies mapping changes with an audit entry2.3s

Common mistake. Running push against production without check first. Mappings are versioned, so a bad change is reversible, but it will re-run the affected reports.
